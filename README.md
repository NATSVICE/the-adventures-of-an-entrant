# Визуальная новелла "Приключения абитуриента"

## 1. Определение целевой аудитории (Target Market)
### Основные сегменты:

* Абитуриенты (старшеклассники, выпускники школ, колледжей).

* Родители абитуриентов (часто принимают активное участие в выборе вуза).

* Студенты младших курсов (могут использовать новеллу для адаптации).

* Преподаватели и кураторы (могут рекомендовать новеллу как учебный материал).

### Портрет пользователя (User Persona):

- Имя: Анна, 17 лет.

- Цель: Выбрать вуз и программу обучения.

- Проблемы: Не понимает, как устроена жизнь в институте, боится ошибиться с выбором.

- Как новелла поможет: Даст реалистичное представление о вузе через интерактивный сюжет.

## 2. Проблемы, которые решает продукт (Customer Problems)
✅ Недостаток информации о реальной жизни в вузе (не только про учёбу, но и про внеучебку, общение, карьерные возможности).

✅ Страх ошибиться с выбором направления ("А вдруг мне не понравится?").

✅ Сложности адаптации (как найти друзей, как общаться с преподавателями и т. д.).

✅ Сухие форматы подачи информации (обычно вузы дают PDF-буклеты или скучные презентации).

## **3. Предложение (Value Proposition)**  
**Чем твоя новелла лучше альтернатив?**  

| **Критерий**         | **Традиционные методы (сайты, буклеты)**      | **Твоя визуальная новелла**                  |
|----------------------|---------------------------------------|---------------------------------------|
| **Подача информации** | Сухая, формальная                    | Интерактивная, игровая, эмоциональная |
| **Вовлечённость**    | Низкая (просто чтение)               | Высокая (выбор решений, последствия)  |
| **Охват тем**        | Учёба, правила поступления           | Учёба + внеучебка, адаптация, карьера |
| **Доступность**      | Нужно искать информацию              | Всё в одном месте, можно пройти за 20-30 минут |

## 4. Каналы распространения (Channels)

### Как абитуриенты узнают о новелле?

* Партнёрство с вузом (размещение на сайте, рассылка абитуриентам).

* Соцсети (TikTok, VK, Telegram — короткие тизеры из новеллы).

* Школы и образовательные выставки (QR-коды на стендах).

* Сарафанное радио (студенты-амбассадоры рассказывают абитуриентам).
