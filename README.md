# Модель монетизации визуальной новеллы для абитуриентов

## 1. Основные потоки доходов

### 1.1. Прямая монетизация
| Модель                     | Описание                                                                 | Целевая аудитория       |
|----------------------------|--------------------------------------------------------------------------|-------------------------|
| **Freemium**               | Бесплатный базовый сюжет + платные расширенные концовки                 | Абитуриенты             |
| **Подписка**               | Доступ ко всем сценариям за ежемесячную плату (200 - 500)                    | Активные пользователи   |
| **Разовые покупки**        | Покупка отдельных премиум-сценариев (1000 - 2000) за сценарий)                  | Родители/преподаватели  |

### 1.2. Косвенная монетизация
| Источник                    | Механизм                                                                 |
|-----------------------------|--------------------------------------------------------------------------|
| **Партнерские программы**   | Комиссия за переходы на сайты вузов-партнеров                            |
| **Брендированный контент**  | Интеграция реальных вузов в сюжет (плата за размещение)                  |
| **Данные для вузов**        | Аналитика по выбору абитуриентов (анонимизированные данные)              |

## 2.Ключевые метрики монетизации

| Метрика                          | Целевое значение (год 1) | Описание                                                                 |
|----------------------------------|--------------------------|--------------------------------------------------------------------------|
| **ARPU** (Average Revenue Per User) | 300                   | Средний доход с одного пользователя в месяц                             |
| **LTV** (Lifetime Value)         | 1000                     | Общий прогнозируемый доход с одного пользователя за всё время           |
| **CAC** (Customer Acquisition Cost)| 100                   | Средняя стоимость привлечения одного платящего пользователя             |
| **Конверсия в платеж**           | 8%                      | Процент пользователей, совершающих хотя бы одну покупку                  |
| **Retention Rate** (30 дней)     | 35%                     | Процент пользователей, остающихся активными через месяц                  |
| **ROI** (Return on Investment)   | 220%                    | Окупаемость маркетинговых вложений                                      |

**Пояснения:**
- 📈 **ARPU** рассчитывается как: `Общий доход / Количество пользователей`
- 💎 **LTV** включает: `ARPU × Средний срок жизни пользователя (7.2 мес)`
- 🎯 **CAC** учитывает: `Маркет. расходы / Количество привлеченных пользователей`
- 🔄 **Retention** критичен для подписной модели
